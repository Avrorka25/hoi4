# Статическая проверка

Проверка использует Python 3 и стандартную библиотеку. Для проверки синтаксиса
Lua нужна системная библиотека liblua5.4; если её нет, отчёт указывает пропуск.
Она компилирует исходный текст, не выполняя его.

После распаковки полного архива:

```bash
python3 tools/validate_mod.py Road_to_56_RP --report validation.json
```

Для проверки вместе с вашей распакованной копией основного RT56:

```bash
python3 tools/validate_mod.py Road_to_56_RP --base /path/to/RT56 --report validation.json
```

Повторные объявления ID проверяются после замены файлов по одинаковому пути.
Учитываются комментарии, строки, вложенные вызовы событий и числовые суффиксы.
Идентификаторы основной игры и других дополнений проверяются только если их
файлы присутствуют в переданном справочнике. Проверка не запускает HOI4,
не воспроизводит движок и не гарантирует отсутствие вылетов.

При наличии map/provinces.bmp и definition.csv в основном RT56 дополнительно
проверяются координаты naval_base_spawn, регион провинции под координатами
и ненулевой ID морской провинции. Чтение bitmap не изменяет изображение.
Самостоятельная проверка портов:

```bash
python3 tools/map_buildings.py Road_to_56_RP --base /path/to/RT56
```

Прежний rufix.2 даёт две ошибки: провинции 13532 и 1351 записаны в другие
регионы. После синхронизации rufix.3 проверка проходит. Предупреждения о
трёх совпадениях sampled pixels также присутствуют в основной карте RT56:
дробные координаты береговых точек не дают точного воспроизведения обработки
геометрии движком; они не изменялись исправлением.
