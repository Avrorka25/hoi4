# Русская локализация RT56 RP v2

Папка `russian` содержит основные языковые исходники;
`external_localisation` содержит файлы, размещённые прямо в localisation
и её общем подкаталоге replace. Они повторяют расположение английских файлов.
Все эти исходники входят в последнюю полную сборку
`RT56RP_v2_HOI4_1.19.zip`. Для обычной установки используйте полную сборку
или `RT56RP_v2_Russian_patch.zip` по [инструкции](../../README_V2_119_RU.md).

Основой служит предоставленный Road to 56 RUS. Его строки применялись при
совпадении английского текста и игровых выражений. Новые строки переведены
локальной моделью Argos EN→RU 1.9; часть интерфейса и военных терминов вычитана
вручную. Полная редакторская вычитка ещё не выполнена.

Для дальнейшей вычитки:

1. Сопоставляйте русский файл с одноимённым английским файлом установленного
   мода. Суффикс `_l_russian` соответствует `_l_english`; папка `replace`
   должна сохраняться.
2. Сохраняйте файлы как **UTF-8 с BOM** и заголовком `l_russian:`.
3. Сохраняйте ключи, выражения `[...]`, ссылки `$...$`, значки `£...`, флаги
   `@TAG`, управляющие последовательности `§...` и `\n`. Внутренние кавычки
   экранируйте: `\"`. Имена картинок `GFX_...` сохраняйте без перевода.
4. Проверяйте правки командой из корня репозитория:

```bash
python3 tools/validate_v2_russian.py /path/to/roadto56rp-new-main --report russian_validation.json
```

Словари проверенных терминов, названий создаваемых государств и интерфейса
находятся в `tools/v2_terms_ru.json`, `tools/v2_formable_names_ru.json`,
`tools/v2_russian_overrides.json` и `tools/v2_interface_translations.json`.
Языковые ключи интерфейса `V2_RU_INTERFACE_*` используются изменёнными .gui;
одного копирования папки russian для обновления интерфейса недостаточно.

`tools/localise_v2.py` выполняет подготовку, перевод, перенос интерфейсных
подписей и сборку. Для этапа `translate` нужны `ctranslate2==4.6.0` и
`sentencepiece==0.2.1`, а также данные модели
`https://argos-net.com/v1/translate-en_ru-1_9.argosmodel`.
Код не исполняет файлы из модельного архива; он проверяет SHA-256 весов и
токенизатора перед загрузкой в библиотеки. Для проверки и ручной вычитки
готовых исходников модель не требуется.

Русский перевод и исходные материалы остаются работой авторов RT56,
Road to 56 RUS и RP-модификации. Обновление сохраняет сведения об авторах
в исходной полной сборке.
