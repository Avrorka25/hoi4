# Road to 56 RP v2 — пакет для HOI4 1.19

Версия пакета: **1.19-v2fix.2-ru**. Исходник — `mod.zip`, добавленный коммитом
`3a2ac69` с сообщением `562v2` в репозитории Avrorka25/hoi4.
Отдельной ветки 56v2 на момент проверки нет; архив находится в main.

Это полный вариант RT56 RP со своей картой, фокусами и правилами.
В игровом наборе включайте **Road to 56 RP v2 (HOI4 1.19)** отдельно от
основного The Road to 56 и прежнего RP-дополнения: их игровые файлы конфликтуют.

- [Накопительный патч для исходного mod.zip](https://github.com/Avrorka25/hoi4/blob/main/RT56RP_v2_HOI4_1.19_patch.zip).

Патч предназначен именно для `roadto56rp-new-main` из mod.zip, а не для
предыдущего дополнения Road_to_56_RP с пакетами rufix.1–rufix.4.

## Установка полной сборки

1. Закройте игру и лаунчер, распакуйте архив.
2. Скопируйте папку **roadto56rp-new-main** и файл **roadto56rp-new-main.mod** в:
   `Документы/Paradox Interactive/Hearts of Iron IV/mod`.
3. Если эта версия уже установлена, замените её файлы. Сохраните отдельно
   собственные изменения перед заменой.
4. В игровом наборе включите **Road to 56 RP v2 (HOI4 1.19)**.
5. Выберите **русский язык** в настройках HOI4.
6. Начните новую партию. Для первого теста используйте набор с этим одним модом.

Русский перевод уже встроен. Отдельный Road to 56 RUS для этой сборки не нужен.

Ожидаемая структура:

```text
mod/
  roadto56rp-new-main.mod
  roadto56rp-new-main/
    descriptor.mod
    common/
    history/
    map/
    ...
```

## Установка патча

Если исходный вариант уже установлен, распакуйте патч и скопируйте его папку
**roadto56rp-new-main** и внешний **roadto56rp-new-main.mod** в ту же папку mod
с заменой файлов. Патч содержит все изменённые и новые файлы. Сам по себе
он не содержит полный мод: сначала нужен исходный mod.zip или полная сборка.

Если у вас уже установлена исправленная **1.19-v2fix.1**, достаточно небольшого
**RT56RP_v2_Russian_patch.zip**: скопируйте его папку roadto56rp-new-main и
внешний .mod в папку mod с заменой. Он содержит перевод, локализованные подписи
интерфейса, локализованные названия альянсов и дескрипторы. Исправления игровых файлов из предыдущего обновления
в языковой патч не входят; для исходного mod.zip используйте накопительный патч.

## Русский перевод

Добавлено **427 русских файлов  138 666 уникальных ключей и 146 662 строки**.
Сохранены исходные повторные строки, их порядок и номера версий.
Проверка пропущенных ключей и изменённых игровых выражений пройдена без ошибок.

Для каждого английского файла создан соответствующий русский файл, включая
подкаталог replace. Перевод охватывает фокусы, события, решения, национальные
идеи, технологии, подсказки, правила RP и инструменты ведущего. Английские
подписи, зашитые в .gui, вынесены в языковые ключи с английским и русским текстом.
Названия альянсов, записанные напрямую в сценариях, также вынесены в языковые
ключи; обратная подстановка восстанавливает исходные сценарии побайтно.
Исправлены четыре исходные ошибки выражений локализации: лишний `$` в имени
Кипра, пропущенные скобки в финском и иракском событиях и лишняя скобка
в описании греческой идеи.
Предупреждение о неподдерживаемом русском языке заменено приветствием.

Основная часть взята из предоставленного **Road to 56 RUS**, только когда
английский текст совпадал и игровые выражения сохранялись. Повторно использованы
совпадающие переводы прежнего RP-дополнения. Новые тексты переведены локальной
моделью Argos EN→RU 1.9; интерфейсные термины, категории войск и названия новых
немецких фокусов дополнительно вычитаны. Полная редакторская вычитка всех
описаний и событий пока не выполнена; в машинной части возможны стилистические
ошибки. Названия производителей, исторические обозначения техники и сокращения
могут сохранять оригинальное написание.

Проверяются наличие всех английских ключей в русском, UTF-8 с BOM, кавычки,
игровые ссылки `$...$`, выражения `[...]`, значки `£...`, цвета `§...` и переводы
строк. Русские исходники доступны в `translations/v2/russian` и `translations/v2/external_localisation` для дальнейшей
вычитки. Отчёт о покрытии — `tools/v2_russian_report.json`.

## Проверка и ограничения

Статическая проверка охватывает сценарии, UTF-8, локализацию, ID определений,
ссылки prerequisites обычных, общих и совместных фокусов, карту, назначение
провинций регионам, победные точки, порты и точки зданий. Lua компилируется
без выполнения. Изображения проверяются по фактическому формату: некоторые
исходные .dds являются PNG/JPEG/TGA; их данные сохранены.

Мод не запускался в HOI4: в Linux-среде нет полной игры и её DLC.
Статические проверки не подтверждают отсутствие всех вылетов или совместимость
старых сохранений. В отчёте отдельно отмечены 10 исходных переопределений
черт лидеров и четыре ссылки технологий, требующие файлов основной игры
или проверки в движке. Новые заглушки для сокрытия ошибок не добавлялись.

После установки проверьте новую партию за Германию. Если игра выдаёт ошибку,
сохраните error.log и game.log из папки logs до следующего запуска.
Если появилась новая папка crashes, также сохраните её содержимое.

## Повторная проверка исходников

Нужны Python 3, Pillow для проверки альтернативных форматов текстур и
liblua5.4 для проверки Lua. Они доступны в проверенной облачной среде.
Проверка не выполняет скрипты мода или hoi4.exe.

```bash
python3 tools/validate_v2.py /path/to/roadto56rp-new-main --report validation.json
python3 tools/validate_v2_russian.py /path/to/roadto56rp-new-main --report russian_validation.json
```

Для повторного применения правок сначала скопируйте распакованный исходник
в отдельную рабочую папку, сохранив имя roadto56rp-new-main:

```bash
python3 tools/update_v2.py /path/to/working/roadto56rp-new-main --base '/path/to/The Road to 56' --source-archive mod.zip --report update.json
```

Инструмент проверяет SHA-256 исходного mod.zip:
`2f5804081f8c7cd7c5debe017b67c5b8f633fd350a48b5972e144758b4fe8f9d`.
Исходный архив в репозитории сохранён без изменения.

Для установки проверенных русских исходников без модели перевода скопируйте
`translations/v2/russian` в `roadto56rp-new-main/localisation/russian`, а содержимое
`translations/v2/external_localisation` — в `roadto56rp-new-main/localisation`. Изменённые
файлы интерфейса и их дополнительные английские ключи берите из языкового патча.
